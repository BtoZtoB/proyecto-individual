Si la PWA ya está activa, marca también Application → Service Workers → Bypass for network durante esta medición. Después presiona el botón. Las cifras corresponden a este navegador y servidor, e incluyen las imágenes de la página.

Para la entrega de clase, conserva también una captura de Network. Un resultado desde caché puede mostrar 0 KB transferidos. El resultado no representa una medición de todos los dispositivos o navegadores.
